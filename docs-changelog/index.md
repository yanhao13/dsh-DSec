## v0.1.6-alpha.2

**Interactive sidebar terminals and a Sidebar Browser, refined desktop distribution, and a Messages-first DeepSeek routing.** The right sidebar becomes an automation surface with interactive terminals, browser tabs, subagent chats, and automatic document/image/PDF previews [PR #3864](https://github.com/deepseek-ai/deepseek-harness/pull/3864), [PR #4379](https://github.com/deepseek-ai/deepseek-harness/pull/4379); a refined Windows install with caption navigation and native recovery dialogs ships on the thin Electron shell [PR #4033](https://github.com/deepseek-ai/deepseek-harness/pull/4033), [PR #4407](https://github.com/deepseek-ai/deepseek-harness/pull/4407). DeepSeek moves to the Messages protocol by default with Files parity while the V4 Flash defaults are dropped [PR #4089](https://github.com/deepseek-ai/deepseek-harness/pull/4089), [PR #4313](https://github.com/deepseek-ai/deepseek-harness/pull/4313), and experimental per-session browser-use backends land [PR #4092](https://github.com/deepseek-ai/deepseek-harness/pull/4092).
